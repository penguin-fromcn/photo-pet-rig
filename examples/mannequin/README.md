# Mannequin demo

Synthetic, MIT-licensed test character generated by `examples/make_mannequin.py`.
It is intentionally flat illustration art, not a photo, and it exists only to
exercise all 14 layers, joint patches, alignment and QA.

Rebuild the output with:

```bash
photopet build examples/mannequin/project.json --out /tmp/photopet-demo --force
```
